# Installation

## Using pip

The recommended way to install LlamaLogalyzer is via pip:

```bash
pip install llamalogalyzer
```

## From Source

You can also install LlamaLogalyzer from source:

```bash
git clone https://github.com/llamasearchai/llamalogalyzer.git
cd llamalogalyzer
pip install -e .
```

## Dependencies

LlamaLogalyzer requires:

- Python 3.8+
- Other dependencies are automatically installed by pip
